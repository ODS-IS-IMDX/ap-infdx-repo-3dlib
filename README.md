# 概要
本リポジトリでは、下記の機能を提供します。
| 機能名           | 機能概要                             |
| ---------------- | ------------------------------------ |
| 座標→空間ID変換 | ポリゴンを空間IDに変換します。         |
| ポリゴン面積取得 | ポリゴン座標をもとに面積を取得します。 |

# リポジトリ利用方法
各環境の詳細は[前提条件](#前提条件)をご参照ください。
1. Dockerfileを使ってコンテナイメージを作成します。

2. Amazon ECSコンテナへデプロイを行います。

# 前提条件
1. ECS on Fargateを準備していることが必要です。
    - コンテナ環境
        | OS/MW/SW   | ディストリビューション | バージョン   |
        | ---------- | ---------------------- | ------------ |
        | Linux      | Debian                 | 12(bookworm) |
        | Python     | -                      | 3.12.4       |
        | Uvicorn    | -                      | 0.31.0       |
        | PostgreSQL | -                      | 15.10        |
